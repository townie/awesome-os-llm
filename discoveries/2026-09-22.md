## Kept out of the README

- **GLM-5.3** ([`zai-org/GLM-5.3`](https://huggingface.co/zai-org/GLM-5.3), [`zai-org/GLM-5.3-BF16`](https://huggingface.co/zai-org/GLM-5.3-BF16)). Both cards exist. The license field is `other` with `license_name: glm-5.3`. The license text was not read, so the README only mentions the name from the MIT-licensed [GLM-5.2](https://huggingface.co/zai-org/GLM-5.2) card, which points at 5.3 as a newer version.
- **Llama 4 Behemoth.** `meta-llama/Llama-4-Behemoth` and `meta-llama/Llama-4-Behemoth-Instruct` returned HTTP 401 from the Hub API. That is not evidence of a public checkpoint. The `meta-llama` org listing checked the same day did not show a Behemoth repository. Omitted.
- **Muse Spark weights.** [Muse Glimmer 30B](https://huggingface.co/meta-models/Muse-Glimmer-30B) is in the README because its card is Apache-2.0 and dates itself to August 2026. The same card says Glimmer was distilled from Muse Spark. No Spark weight card was opened, so Spark is not listed as an open model.
- **DeepSeek chat and OpenAI marketing pages.** `chat.deepseek.com` and `openai.com/open-models` returned HTTP 403 to this client. The README uses the GitHub and Hugging Face pages that did load.
- **r/LocalLLaMA fetch.** The subreddit URL is in the README because it is the long-standing local-model forum. Reddit returned HTTP 403 to this client, which is recorded on the bullet and in [`SOURCES.md`](../SOURCES.md).
